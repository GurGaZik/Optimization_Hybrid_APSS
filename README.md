# Оптимизация гибридной Автономной Системы Электроооснабжения (АСЭС)
## Краткое описание
Программа реализует алгоритм внедрения ВИЭ в существующую энергосистему г. Северо-Курильска (о. Парамушир) с существующей системой генерации состоящей из двух МГЭС и одной ДЭС. ПО выполняет многокритериальную оптимизацию состава оборудования на годовом и суточном интервалах.

Основная цель - разработка математических моделей, алгоритмов оптимизации и программного обеспечения для расчета режимов работы гибридной АСЭС на базе существующих ДЭС и МГЭС с внедрением ВЭУ и АКБ, обеспечивающих выбор оптимального состава оборудования и снижение доли дизельной генерации в покрытии графика электрической нагрузки.
